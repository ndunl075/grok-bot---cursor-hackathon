# Canvas Student Assistant — Grok Bot

A proactive Canvas bot that texts you first. It knows what's due, what it's worth,
and what it does to your grade — and it tells you before it's a problem.

Setup is two things: your Canvas URL and a personal access token. No school-specific
config, no paid services, no code to run.

- **[ARCHITECTURE.md](ARCHITECTURE.md)** — the build contract. Read this first.
- **[docs/CANVAS_API.md](docs/CANVAS_API.md)** — endpoint reference.
- **[docs/DEMO_SCRIPT.md](docs/DEMO_SCRIPT.md)** — shot list for the video.
- **[PUBLISH_CHECKLIST.md](PUBLISH_CHECKLIST.md)** — run before exporting the template.

## What ships in the template

`bot/INSTRUCTIONS.md`, everything in `skills/`, everything in `routines/`.
